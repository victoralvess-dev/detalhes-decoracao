# Detalhes Decorações e Paisagismo

Site institucional para uma empresa de decoração de eventos e paisagismo de Natal/RN, desenvolvido para a empresa da minha família.

🔗 **Site no ar:** https://victoralvess-dev.github.io/detalhes-decoracao/

> Projeto em desenvolvimento.

## Sobre o projeto

Este projeto nasceu de uma necessidade real: ajudar meus pais a ter presença na internet e, ao mesmo tempo, praticar o que aprendo no curso de informática para internet.

## O que já está pronto

- Cabeçalho com menu de navegação, adaptado para celular
- Seção de abertura da página inicial, com botões de orçamento e WhatsApp
- Formulário de orçamento (estrutura em HTML e estilo em CSS)

## O que vem a seguir

- Carrossel de fotos dos trabalhos (JavaScript)
- Páginas "Quem somos", "Serviços" e "Locações"
- Rodapé com contato

## Tecnologias

- HTML5
- CSS3 (Flexbox, Grid e Media Queries)
- JavaScript

## O que estou aprendendo com este projeto

- Criar layouts responsivos com foco em celular
- Usar HTML semântico e formulários
- Publicar um site com Git e GitHub Pages
